# MUN de France 2027 — site statique

Le dossier est prêt à être publié comme site statique sur Cloudflare Pages. Il ne nécessite ni compilation ni dépendances à installer.

## Déploiement avec GitHub

Dans Cloudflare Pages, connectez le dépôt GitHub puis configurez :

- Répertoire racine : `outputs/mun-de-france` si vous conservez ce chemin dans le dépôt ; sinon, choisissez le dossier dans lequel vous placez les fichiers.
- Commande de build : laisser vide.
- Répertoire de sortie : `.`

Si vous placez le contenu de ce dossier à la racine du dépôt, choisissez cette racine comme répertoire racine.

## Avant publication

Vérifier et remplacer les éléments provisoires :

- le mot du Secrétaire général ;
- les chiffres, la date et les lieux ;
- les commissions et présidences ;
- les adresses `contact@mundefrance.fr` et `presse@mundefrance.fr` par les adresses officielles.

Le dossier de partenariat adressé à Assas n’est pas intégré au site public. Les formulaires ne sont pas présents dans cette version.
